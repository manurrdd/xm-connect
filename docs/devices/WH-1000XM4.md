# WH-1000XM4

Answers on the legacy service, so it speaks the v1 command table. Captured with `xmprobe`:

```
recv     01 00 70 00
recv     07 00 17 71 38 62 F5 81 51 A1 E1 E2 D2 F6 D1 F4 F3 39 12 13 11 30 C1 14 22 21
```

Protocol version `0x7000`, reported as a 16-bit value with no table-support bytes after it.

Twenty-three announced functions, in the order the device lists them:

| Id | Function |
|---|---|
| `71` | adaptive sound control |
| `38` | paired device management |
| `62` | noise cancelling + ambient sound |
| `F5` | speak-to-chat |
| `81` | noise cancelling optimizer |
| `51` | preset equalizer |
| `A1` | playback controller |
| `E1` | connection mode |
| `E2` | upscaling (DSEE) |
| `D2` | general setting 2 |
| `F6` | assignable controls |
| `D1` | general setting 1 |
| `F4` | auto power off |
| `F3` | playback control by wearing |
| `39` | voice guidance |
| `12` | upscaling indicator |
| `13` | codec indicator |
| `11` | battery level |
| `30` | firmware update |
| `C1` | action log |
| `14` | BLE setup |
| `22` | concierge data |
| `21` | power off |

Battery is reported as a single level: neither the left/right (`15`) nor the case (`18`) layout is
announced, as expected for an over-ear model. The touch panel toggle lives in one of the two
general-setting slots, which have to be read to find out which.
